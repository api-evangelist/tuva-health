# Tuva Health

> Tuva Health, Inc. is a US healthcare data company behind The Tuva Project, an open-source, warehouse-native data-transformation platform that harmonizes, validates, normalizes, and enriches raw healthcare data (medical and pharmacy claims, EHR clinical data, ADT feeds, HL7 FHIR) into an analytics-ready Core Data Model and a library of Data Marts. It runs as a dbt package plus Python utilities inside the customer's own cloud data warehouse (Snowflake, Databricks, BigQuery, Redshift, Microsoft Fabric) — it is open-source software, not a hosted HTTP or FHIR API.

## Products
- [The Tuva Project (dbt package)](https://thetuvaproject.com/getting-started): Core open-source dbt package transforming Input Layer data into the Core Data Model and Data Marts.
- [FHIR Inferno](https://github.com/tuva-health/FHIR_inferno): Python CLI that flattens nested HL7 FHIR JSON into flat CSV files for the Input Layer.
- [Tuva Connectors](https://thetuvaproject.com/connectors/overview): dbt connector projects (Medicare CCLF, BCDA, CMS synthetic, Aetna, Epic, eClinicalWorks, and a template) that map raw source formats into the Input Layer.
